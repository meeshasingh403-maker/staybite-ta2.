1. Problem Statement & Architecture

          
          

            Problem Statement: Travelers often use separate apps to check destination context, find nearby Airbnb/hotel stays, and inspect in-house or local food menus. StayBite unifies location discovery, stay filtering, and categorized food menus into a single mobile-first interface.           

          
            
              Presentation Layer (UI/UX):               Mobile-first viewport shell, bottom tab navigation, dynamic filter pills, and interactive bottom-sheet drawer.             
            
              Location Service Layer:               HTML5 Geolocation API (`navigator.geolocation`) with fallback city selector returning coordinates, weather, and area vibe.             
            
              Data & State Layer:               Structured JSON repository mapping regions to stays (Airbnb/Hotels) and nested categorized menus (Breakfast, Main Course, Beverages) persisted via `localStorage`.

  • Frontend Markup & Styling: Semantic HTML5 + Tailwind CSS utility framework for responsive mobile ergonomics.
    •             
  • Application Logic: Modular Vanilla JavaScript (ES6+) managing reactive state, filtering, and DOM rendering.
    •             
  • Device APIs: Geolocation API for live latitude/longitude detection and Web Storage API (`localStorage`) for bookmarking stays & meals.
